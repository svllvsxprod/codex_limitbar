## What's new

- Shows the number of available manual Codex limit resets below the usage limits.
- Refreshes the reset count together with usage data, using the account signed in to the app.
- Shows “—” when the server does not provide a valid count, rather than incorrectly showing zero.
- Supports Russian and English labels and explanations.

## Installation

Users on 0.4.0 can install this update from **Settings → Check for Updates…**. For a manual installation, move **Codex Limit Bar.app** from the DMG into **Applications**.

Requires macOS 14 or later on Apple Silicon. This GitHub build is ad-hoc signed and is not notarized by Apple. The update feed and archive are signed with the existing Sparkle Ed25519 key.
