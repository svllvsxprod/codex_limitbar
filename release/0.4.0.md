## What's new

- Adds a settings button in the top-right corner of the menu panel.
- Gives buttons more padding and keeps the rounded menu panel stable when opening the updater.
- Shows the menu bar icon and a readable percentage side by side.
- Offers launch at login on the first installed launch, with an on/off switch that reflects macOS settings and explains when approval is needed.
- Adds automatic update checks every six hours and a manual “Check for Updates…” button.
- Offers new GitHub releases through Sparkle, then downloads, verifies, installs, and relaunches after confirmation.
- Signs the update feed and archives with Ed25519; update archives are verified before extraction.
- Fixes app packaging with newer Swift toolchains.

## Installation

Move **Codex Limit Bar.app** from the DMG into **Applications**, then launch it there. Users of 0.3.0 and earlier need to install this release manually once; subsequent releases can be installed through the app.

Requires macOS 14 or later on Apple Silicon. This GitHub build is ad-hoc signed and is not notarized by Apple. Sparkle update signatures are separate from Apple code signing.
